# Kalnmuiža — Heritage Editorial demo

Neoficiāls viesu nama Kalnmuiža mājaslapas priekšskatījums, veidots pēc **WEBAGENCY_OS MASTER** principiem.

## Priekšskatījums

- [Atvērt pilnu lapu pārlūkā](https://raw.githack.com/davisl24/kalnmuizas/demo/heritage-editorial-v1/index.html) — trešās puses GitHub HTML skatītājs; ne Vercel deployment.
- [Alternatīvais HTML Preview](https://htmlpreview.github.io/?https://github.com/davisl24/kalnmuizas/blob/demo/heritage-editorial-v1/index.html) — ja pirmais skatītājs nav pieejams.

Šīs ir neoficiālas skatīšanas saites, nevis produkcijas domēns. Fotogrāfijas vēl nav pievienotas un vietas pašreizējais darbības statuss joprojām nav apstiprināts.

## Atvērt
Failu `index.html` var atvērt lokāli pārlūkā bez instalēšanas. Tā ir patstāvīga HTML/CSS lapa bez npm, servera, formu vai datubāzes atkarībām.

## Sekcijas
Hero → Par Kalnmuižu → Svinības un atpūta → Galerija → Atrašanās vieta → Kontakti.

## Darba gaita
- **Darba zars:** `demo/heritage-editorial-v1`
- **Galvenais zars:** `main` pagaidām satur tikai inicializācijas README.
- **Statuss:** pirmā versija izstrādāta; pārlūka QA, klienta informācijas un foto izmantošanas tiesību pārbaude vēl jāveic.
- **Publikācija:** nav apstiprināta; neapvienot ar `main` un neizvietot kā oficiālu vietni bez saskaņošanas.

## Faktiskā informācija un fotogrāfijas
2023. gadā tika ziņots par ugunsgrēku viesu namā. Pašreizējais darbības statuss, kapacitāte, kontakti un cenas vēl jāprecizē. Tāpēc lapa neapgalvo, ka pieņem rezervācijas.

Nav izmantotas stock vai AI fotogrāfijas; galerijas vietturi jāaizvieto tikai ar reāliem, aktuāliem Kalnmuižas foto, kam ir atbilstoša publicēšanas atļauja.
