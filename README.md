# Kalnmuiža — Heritage Editorial demo

**Aktīvais darbs:** `feature/svinibas-page-v1` (GitHub `main` nav mainīts).

## Lapas
- `index.html` — īsa sākumlapa.
- `svinibas.html` — svinību iespējas.
- `naksnosana.html` — nakšņošana un apstiprināmie fakti.
- `galerija.html` — foto vietas (vēl nav klienta fotogrāfiju).
- `kontakti.html` — saziņa, atrašanās vieta un maršruts.

## Publiskā demo apskate
https://kalnmuizas-demo.vercel.app/

## Lokāli
```bash
git fetch origin
git switch feature/svinibas-page-v1
git pull origin feature/svinibas-page-v1
```
Atver `index.html` ar VS Code Live Server. Šī ir statiska HTML/CSS lapa; nav vajadzīgs `npm install`.

## Dizaina sistēma un robežas
KESTREL Visual Direction v1.1: Manrope, 1280 px konteiners, desktop/mobile 40/20 px sānu malas, 96/64 px sadaļu atstarpes, H1/H2/H3 72/48/30 un 40/32/24 px. KARLE ir kompozīcijas, nevis kopējama satura/identitātes atsauce.

Neoficiāls demo ar `noindex,nofollow`. Publiskie pakalpojumu apraksti var būt novecojuši; īstās fotogrāfijas, cenas, guļvietas un nosacījumi vēl jāapstiprina. Projekts ir Vercel izolētā demo vidē, nevis oficiālajā Kalnmuižas domēnā. Pēdējai versijai izieta statiskā QA; desktop/mobile vizuālā QA nav apstiprināta.

Aktuālie lēmumi un QA statuss — `PROJECT_STATE.md`.
